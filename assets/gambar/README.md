## Aturan Format Gambar Sesuai Template SIMASI

1. **Posisi Judul (*Caption*):** Wajib diletakkan **DI BAWAH GAMBAR**, Rata Tengah (**Center**).
2. **Format Teks:** Font Times New Roman $12\text{ pt}$, Title Case, Spasi baris Single ($1{,}0$).
3. **Spasi Paragraf Caption:** Spacing Before: $2\text{ pt}$, Spacing After: $6\text{ pt}$.
4. **Lebar Gambar:** Proporsional dan rata tengah (lebar maksimum $16\text{ cm}$ agar tidak keluar dari batas margin kertas Letter/A4 $2{,}54\text{ cm}$).
